새롭게 신설된 ⭐️ Product Engineering(PE) ⭐️ 세미나에서는 AI를 적극 활용해 아이디어를 실제 서비스로 구현합니다. 앱 서비스 기획부터 프론트엔드·백엔드 개발, 출시까지 전 과정을 직접 경험하며 하나의 서비스를 end-to-end로 완성하는 것을 목표로 합니다. **(PE 세미나는 정회원과 Rookie가 함께 수강하며, Rookie는 PE 세미나만 단독으로 수강할 수 없습니다.)**

### React - Frontend

- 예상 일정: 월요일 19~21시 (9/14, 9/21, 9/28, 11/9, 11/16, 11/23)
- 세미나 목표: React의 핵심 개념을 익히고, 실제 웹 서비스 개발 과정에 필요한 역량을 갖추는 것을 목표로 합니다.
- 커리큘럼:
    - 1주차: useState
    - 2주차: useEffect, useRef, 라우터
    - 3주차: 스토리지, 클라이언트 전역상태관리, 스타일링 라이브러리
    - 4주차: Promise
    - 5주차: 서버, 인증/인가, 서버 상태관리, 실시간 통신
    - 6주차: https vs http, 배포, 협업
- 선이수 지식: html/css 및 js 기초 문법에 대한 이해

### FastAPI - Backend

- 예상 일정: 토요일 오후 2시 반~5시 (9/12, 9/19, 10/3(비대면), 10/31, 11/7, 11/21, 11/28)
- 커리큘럼:
    - Python 기반의 FastAPI 프레임워크를 활용하여 RESTful API 백엔드 서버를 개발합니다. 
    - 데이터 검증, 데이터베이스 연동, JWT 기반 인증 처리 등을 학습합니다.
    - AWS, Docker 등을 활용한 서비스 실전 배포까지 경험할 수 있도록 구성할 예정입니다.
- 선이수 지식: 변수, 조건문, 반복문, 함수, 클래스 등의 Python 기초 문법

### Spring - Backend

- 예상 일정: 화요일 오후 7시 ~ 9시 (9/8, 9/22, 10/6)
  - 4, 5주차 세부 일정 및 진행 장소는 추후 공지할 예정
- 세미나 목표: Spring Boot를 활용해 기본적인 웹 애플리케이션을 구현하고, 데이터베이스 연동부터 테스트와 배포까지의 전체 흐름을 경험합니다.
- 커리큘럼:
    - 1주차: Spring Boot와 REST API 기초
    - 2주차: 데이터베이스와 Spring Data JPA
    - 3주차: 애플리케이션 구조와 인증·예외 처리
    - 4주차: 트랜잭션, 동시성, 테스트
    - 5주차: Docker와 애플리케이션 배포
- 선이수 지식: Java 프로그래밍 경험이 있으면 따라오기 편합니다.

### Product Engineering

- 예상 일정: 토요일 오후 1시 (9/12, 10/31, 11/7, 11/14, 11/21) & 9/29 화요일 오후 7시 (비대면)
- 세미나 목표: 내 주변 문제를 해결할 수 있는 제품을 모바일 앱으로 만들어보기
    - 내 주변의 문제를 찾아 PRD와 목업으로 해결방안을 고안
    - 제품 요구사항을 화면·데이터·API 설계로 옮기고, 시스템 전체(프런트/백/DB/인프라)를 이해
    - Claude Code 등 AI 에이전트와 함께 유지보수 가능한 코드 작성
    - CI/CD를 갖추고 iOS/Android 앱 배포
- 커리큘럼:
    - 1주차: 문제 발견과 제품 정의
    - 2주차: 시스템 설계, 프로젝트 셋업
    - 3주차: E2E 핵심 기능 구현
    - 4주차: MVP 완성 및 검증
    - 5주차: iOS/Android 베타 배포와 운영
    - 6주차: 제품 시연, 발표
- 선이수 지식: 한 가지 프로그래밍 언어로 간단한 프로그램을 작성해본 경험 (언어 무관)
- 필요 환경: 안드로이드 스마트폰 or 아이폰
